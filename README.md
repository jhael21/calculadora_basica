\# Calculadora Básica



\## Descripción



Calculadora Básica es un proyecto desarrollado para realizar operaciones matemáticas básicas de una manera sencilla. La aplicación permite al usuario ingresar dos valores y seleccionar la operación que desea realizar.



\## Objetivo



El objetivo principal del proyecto es desarrollar una calculadora funcional aplicando conocimientos básicos de programación, validación de datos y manejo de un repositorio mediante Git y GitHub.



\## Funcionalidades



\* Ingreso de dos valores numéricos.

\* Suma de dos números.

\* Resta de dos números.

\* Multiplicación de dos números.

\* División de dos números.

\* Validación de los datos ingresados.

\* Control de operaciones no válidas.



\## Tecnologías utilizadas



\* HTML

\* JavaScript

\* Visual Studio Code

\* Git

\* GitHub

```text

calculadora\_basica/

│

```



\### index.html



Contiene la estructura y funcionamiento principal de la calculadora.



\### .gitignore



Contiene las reglas utilizadas para evitar que archivos temporales, configuraciones personales y otros recursos innecesarios sean incluidos en el repositorio.



\### README.md



Contiene la documentación del proyecto, sus funcionalidades, tecnologías utilizadas, estructura, ejecución e historial de versiones.



\## Instalación o ejecución



1\. Clonar el repositorio desde GitHub.

2\. Abrir la carpeta `calculadora\_basica`.

3\. Abrir el archivo `index.html`.

4\. Ejecutar el archivo utilizando un navegador web.

5\. Ingresar los valores y seleccionar la operación que se desea realizar.
